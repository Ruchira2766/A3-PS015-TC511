## Project Overview

This repository contains the code, documentation, presentation, and other resources developed by our team for the AIORI-3 Hackathon.

Our project focuses on **Explainable Network Diagnosis**, with the goal of helping identify network problems and provide understandable explanations for their possible root causes.
